Round 01 · Streaming responses
Next.js
app/api/chat/route.tsimport { streamText, convertToModelMessages } from "ai";

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: "anthropic/claude-sonnet-4.5",
    messages: await convertToModelMessages(messages),
  });
  return result.toUIMessageStreamResponse();
}
  • Streaming is the default path, not an option
  • Same protocol the client hook reads
PHP
routes/web.php · PrismRoute::post('/chat', function (Request $request) {
    return Prism::text()
        ->using(Provider::Anthropic, 'claude-sonnet-4-5')
        ->withPrompt($request->string('prompt'))
        ->asEventStreamResponse();
});
  • Short and readable, Server-Sent Events out of the box
  • Each open stream pins a PHP-FPM worker (round 2)
  • Output buffering in nginx or FPM can silently break streaming
Round toNext.jsBoth can stream. In Next.js it is the paved road from server to screen.
Round 02 · Holding thousands of open streams
Node.js event loop

One process holds many sockets. While a stream waits on the model it costs memory, not a thread.

● busy   ○ open and waiting on tokens · one process
  • Thousands of concurrent streams per instance
  • On serverless, watch function duration limits and cost per second
PHP-FPM share-nothing

One worker per request. A 30 second stream blocks that worker for 30 seconds.

worker 1
worker 2
worker 3
request 4queued · pm.max_children reached
  • Octane on FrankenPHP or Swoole fixes much of this
  • Octane means long-lived state, leaks and package compatibility to manage
Round toNext.jsAsync I/O is the native model in Node. In PHP it is an upgrade you opt into.

React + AI SDK UI

  • Tool calls render as real components, typed
  • Shadcn and AI Elements give chat UI kits for free
Livewire or Inertia
  • Livewire wire:stream streams text into the page with no JS build
  • Rich chat state, tool cards, retries and optimistic updates push you toward JavaScript
  • Inertia + React works well, but now you run React anyway, just without the React AI hooks wired to your backend
  • Fewer ready-made AI UI kits
Round toNext.jsAI products live in the interface. The best AI UI tooling is React-first.
Round 04 · SDKs and ecosystem
TypeScript
  • Every major lab ships an official TypeScript SDK, often on day one of a new feature
  • MCP reference SDK, agent frameworks (Mastra, LangGraph.js), evals and tracing all land in TS early
  • AI SDK swaps providers by changing one string
  • Moves fast. Majors every year, migrations to keep up with
PHP
  • Laravel AI SDK: agents, tools, embeddings, images, audio, vector stores
  • Prism: mature multi-provider layer, can even emit the Vercel data stream format
  • laravel/mcp to expose your app to agents
  • New provider features often reach PHP weeks or months later, via community wrappers
Round toNext.jsPHP's AI story is now good. TypeScript's is where the industry ships first.
Round 05 · Structured output and types
Zod in, typed object out
const { output } = await generateText({
  model,
  prompt,
  output: Output.object({
    schema: z.object({
      sentiment: z.enum(["pos", "neg"]),
      score: z.number(),
    }),
  }),

output.score; // number, checked at compile time
  • One schema validates the model and types your code
Schema objects, array out
$res = Prism::structured()
    ->using(Provider::OpenAI, 'gpt-5')
    ->withSchema(new ObjectSchema('review', 'Review', [
        new EnumSchema('sentiment', '', ['pos', 'neg']),
        new NumberSchema('score', ''),
    ]))
    ->withPrompt($prompt)
    ->asStructured();

$res->structured['score']; // mixed: no compile-time type
  • Works, but the type ends at the array boundary
Round toNext.jsModel output is untrusted input. End-to-end types catch it before users do.
Round 06 · Background jobs and agents
Next.js
  • AI SDK agent loops with tools and stop conditions
  • Durable runs via Vercel Workflow, Inngest or Trigger.dev
  • None of it ships with Next.js. Pick a vendor or run BullMQ and Redis yourself
  • Serverless timeouts push long agent runs out of the request
Laravel
  • Queues, retries, backoff, batching, rate limiting: built in
  • Horizon dashboard to watch every agent job
  • Scheduler for nightly embeddings, evals, digests
  • Laravel AI SDK agents can run queued
Round toPHPLaravel's queue story is ten years mature and costs zero vendors.

Round 08 · Hosting and running cost
Next.js
  • Vercel: push to deploy, previews, edge, observability
  • Long streams bill as compute time. Usage pricing can surprise at scale
  • Self-hosting works with Docker, but some features are tuned for Vercel
PHP
  • Runs on a 5 dollar VPS. Forge and Laravel Cloud make it one click
  • Predictable flat cost, no vendor lock
  • You size workers or move to Octane for stream-heavy load
Round toPHPCheaper and plainer to run. Close round: the model bill dwarfs both.

Honest cornerWhen PHP is still the right call

Pick Laravel if

A

You already run Laravel

Adding AI to an existing app beats a rewrite. Laravel AI SDK drops straight in.

B

AI is a feature

Summaries, classification, search in an admin-heavy app. Mostly async jobs, little live UI.

C

Your team is PHP

A senior Laravel team ships faster than a junior TS team. People beat stacks.

The hybrid that works

Laravel as API, queues and admin. Next.js as the AI front end with AI SDK UI, streaming straight from Prism in the same wire format.
